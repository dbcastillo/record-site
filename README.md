# Kool Kat Records

An interactive music catalog website combining modern frontend development with a music-focused user experience.

## Project Overview

This project explores the intersection of music, web development, and digital design through a dedicated record label website.

The application demonstrates component-based development, frontend styling, and user interface design.

## Technologies

- React
- JavaScript
- Tailwind CSS
- Vite
- ESLint

## Getting Started

Install dependencies:

    npm install

Start the development server:

    npm run dev

Build for production:

    npm run build
